# Гидрорасчёт трубы — Android-приложение

Нативное Android-приложение для **гидравлического расчёта трубопровода**.
Формулы и справочные данные в точности соответствуют онлайн-калькулятору
[prostobuild.by](https://prostobuild.by/onlainraschet/244-gidravlicheskiy-raschet-truboprovoda-onlayn.html)
(эталонные значения сняты с оригинального JavaScript-кода калькулятора).

## Возможности

- **3 метода расчёта** — как на сайте:
  - *Таблицы Шевелева* — эмпирические формулы `1000i = tk·(q^tb / d^tm)`;
  - *Теоретическая гидравлика* — число Рейнольдса, коэффициент трения λ
    (Пуазейль / Блазиус / Альтшуль), потери на трение и в местных сопротивлениях;
  - *СНиП 2.04.02-84* — формула с табличными коэффициентами A₀, 1000·A₁, C, m.
- **11 материалов труб** и **10 значений эквивалентной шероховатости** — зашиты как на сайте.
- Плотность и вязкость воды автоматически зависят от средней температуры.
- Расход в **л/с или м³/час**.
- Результаты: скорость, Re, λ, 1000i, характеристика сопротивления S, Па/(т/ч)²,
  потери давления в кгс/см², Па и м вод. ст.
- **График** зависимости потерь давления от внутреннего диаметра (лог-шкала),
  зелёная зона оптимальных скоростей 0,25–1,5 м/с, красная переходная зона Re.
- **Подбор оптимального диаметра** и подходящих условных проходов.
- **Экспорт**: копирование отчёта в буфер и «Поделиться» (WhatsApp, Telegram, почта…).
- Работа **полностью офлайн**, без разрешений и без рекламы.

## Сборка APK в Android Studio (самый простой путь)

1. Установите [Android Studio](https://developer.android.com/studio) (если её ещё нет).
2. Распакуйте архив проекта в любую папку.
3. **File → Open…** и выберите папку `HydroCalc` (где лежит `settings.gradle.kts`).
4. Дождитесь окончания **Gradle Sync** (при первом открытии скачаются Gradle,
   Android Gradle Plugin и зависимости — нужен интернет, это 2–5 минут).
5. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
6. Внизу появится уведомление — нажмите **locate**; откроется папка с файлом
   `app/build/outputs/apk/debug/app-debug.apk`.

## Сборка APK через GitHub — вообще без установки чего-либо

В проект уже включён файл-рецепт `.github/workflows/build.yml`. GitHub
сам соберёт APK на своих серверах:

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно).
2. Нажмите **+** (правый верхний угол) → **New repository** → придумайте имя
   (например, `hydrocalc`), оставьте **Public**, нажмите **Create repository**.
3. На открывшейся странице нажмите ссылку **uploading an existing file**.
4. Перетащите в окно браузера **всё содержимое папки `HydroCalc`** (папки
   `app`, `gradle`, `.github` и файлы `gradlew`, `settings.gradle.kts` и т.д.).
   Папка `.github` — скрытая; убедитесь, что в проводнике включён показ
   скрытых файлов и она тоже попала в загрузку.
5. Внизу нажмите **Commit changes** (загрузка ~47 файлов, займёт минуту).
6. Откройте вкладку **Actions** — там уже началась (или начнётся через пару
   секунд) сборка **Build APK**. Первая идёт 5–10 минут, дальше быстрее.
7. Когда сборка станет зелёной (✓), откройте её и в разделе **Artifacts**
   скачайте **app-debug-apk**.
8. Внутри архива — `app-debug.apk`. Перекиньте на телефон и установите.

Сборку можно перезапустить вручную: **Actions → Build APK → Run workflow**.
Каждый новый push (обновление файлов) тоже запускает сборку заново.

> Если при загрузке через браузер папка `.github` не видна — создайте файл
> вручную: в репозитории **Add file → Create new file**, введите имя
> `.github/workflows/build.yml` и вставьте содержимое этого файла из проекта.

## Сборка из командной строки (без Android Studio GUI)

Нужен только JDK 17 и скачанный Android SDK (command line tools) с переменной `ANDROID_HOME`.
Android SDK Platform 34 должен быть установлен:

```bash
# Linux / macOS
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`

## Установка на телефон

1. Перекиньте `app-debug.apk` на телефон (или скачайте напрямую).
2. Откройте файл; Android спросит разрешение «устанавливать приложения
   из этого источника» — разрешите.
3. Готово: приложение «Гидрорасчёт трубы» появится в меню.

> **Релизная версия:** `./gradlew assembleRelease` соберёт
> `app-release-unsigned.apk` — неподписанный APK установить нельзя.
> Для личного использования достаточно debug-версии; для публикации
> в магазине подпишите APK своим ключом (Build → Generate Signed Bundle/APK).

## Проверка корректности расчёта

Эталонные значения для тестов получены запуском **оригинального JavaScript
калькулятора prostobuild.by** в Node.js (13 сценариев покрывают все методы
и все ветки формул: ламинарный, Блазиус, Альтшуль, обе таблицы СНиП для

```bash
./gradlew test          # или в Android Studio: правый клик на HydroCalculatorTest → Run
```

## Формулы (кратко)

Общее для всех методов:

- плотность воды: `ρ(t) = (−0,003·t² − 0,1511·t + 1003,1)/1000`, т/м³
- скорость: `v = 4q/(ρ·π·d²вн)`, м/с
- характеристика сопротивления: `S = ΔP/(q·3600)²`, Па/(т/ч)²

| Метод | Удельные потери 1000i (м вод. ст./км) | Потери |
|---|---|---|
| Шевелев | `tk·(q^tb / d^tm)` | `ΔP = 1000i·9,81·L`, Па |
| Теория | — | `R = λ·v²·ρ/(2·9,81·d·10)` кгс/(см²·м); `ΔPмс = Σζ·v²·ρ·1000/(2·9,81·10000)` |
| СНиП 2.04.02-84 | `(A1000/19,61)·((A0 + C/v)^m / d^(m+1))·v²` | `ΔP = 1000i·9,81·L`, Па |

Вязкость воды (формула Пуазейля): `ν = 0,0178/(1 + 0,0337·t + 0,000221·t²)·10⁻⁴`, м²/с.

Шероховатость и сумма коэффициентов местных сопротивлений используются
в методе «Теоретическая гидравлика» — так же, как в исходном онлайн-калькуляторе.
